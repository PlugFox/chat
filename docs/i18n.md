# Internationalization

English and Russian first. Messages are ICU MessageFormat, formatted with
`intl-messageformat`; plurals use the locale's CLDR rules (Russian has
`one`/`few`/`many`/`other`).

- `client/src/i18n/messages/en.ts` is the source: every key is defined there.
  Other locales are typed `Messages`, so a missing or extra key fails the type
  check. `tests/unit/i18n.test.ts` also checks that every message parses and
  uses the same arguments as English.
- Components get text through `useI18n().t("area.key", { values })`. No
  user-visible string is hardcoded, including `aria-label`s.
- Locale: the saved choice (`localStorage.locale`), else the first supported
  browser language, else English. Changing it updates `<html lang dir>` and
  every string at once.
- Language names are written in their own language in the selector.
- RTL: `direction()` sets `dir`; the CSS uses logical properties only, so an
  RTL locale needs no style changes.
- The recovery key words are always the BIP-39 English list
  ([crypto.md](crypto.md#ark-wraps)), in every UI language.

Adding a string: the `add-string` skill. Adding a locale: a file in
`messages/`, the code in `locales.ts`, its name in Settings.
